Programa criado para mostrar ao usuario o consumo de energia dos aparelhos eletricos.

## Linguagem usada:

(PYTHON).

## Formula ultilizada para calculo:

```
(potencia * horasDia * 30) / 1000
```

## Instruções de uso:

1. Digitar o nome do aparelho.
2. Digitar a potencia em watts.
3. Digitar horas de consumo diario.
4. Resultado total gasto mensal.
